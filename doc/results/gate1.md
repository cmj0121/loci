# Benchmark results (g1)

> Snapshot of a benchmark report produced on the gate-0 worktree branch (`feat/loci-mvp-plan`); paths below refer to that branch. Key tables only: the cold/warm and prompt-hook tables are left out.

Generated by `bench/report.py --out-dir bench/out/g1`; procedure in `PLAN_DETAILS.md` D16 and `doc/measurement.md`. Runs were interleaved per task (A, E0, Eod, A, …). A concept run is correct when its `ANSWER: path:line` is in an accepted range and the reply has an alias of every `must_mention` item; at file level the answer's file is enough. A feature run is correct when its `ANSWER:` lines hit ≥ 60% of the task's functions and ≥ 50% of them hit one.

Tokens are input + output + cache read + cache write, summed over every model of the session. CIs are bootstrap 95% intervals of arm − A (5,000 resamples of runs within each task, seed 14); negative means the arm is cheaper than A.

Eodf (gate 1b, `PLAN_DETAILS.md` D18) ran later and alone; it is compared with the g1 A and E0 runs, so drift between the two sessions is not controlled. Its CIs use their own bootstrap stream (seed 15), so the other arms' figures are unchanged.

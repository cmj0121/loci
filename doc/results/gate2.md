# Benchmark results (g2, g2s)

> Snapshot of two benchmark reports produced on the gate-0 worktree branch (`feat/loci-mvp-plan`); paths below refer to that branch. Gate 2 (Haiku batch notes) comes first, gate 2s (Sonnet batch notes) second.

Tokens are input + output + cache read + cache write, summed over every model of the session. CIs are bootstrap 95% intervals of arm − A (5,000 resamples of runs within each task, seed 14); negative means the arm is cheaper than A. A concept run is correct when its `ANSWER: path:line` is in an accepted range and the reply has an alias of every `must_mention` item; at file level the answer's file is enough. Only claude-sonnet-5-5 runs are counted. Tasks are the r5 concept tasks.
